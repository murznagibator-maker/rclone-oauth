Privacy Policy

Last updated: September 17, 2026

Purpose

Rclone Google Drive Backup is a personal application used by its owner to create and transfer automated backups to Google Drive using rclone. The application is not offered as a public service.

Google User Data

The application accesses the owner's Google Drive account only for the purpose of uploading, accessing, and managing backup files.

Data Sharing

Google user data accessed by this application is not sold, shared, or transferred to third parties.

Data Storage

OAuth credentials required by rclone are stored locally on systems controlled by the application owner. The application does not operate a separate service that collects or stores Google user data.

Data Protection

Access to Google user data is limited to the application owner and is used solely for personal backup purposes.

Contact

Questions regarding this privacy policy may be directed to the developer contact email associated with the application's Google Cloud project.
